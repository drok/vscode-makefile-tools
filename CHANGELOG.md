# What's New?

## Autotools Integration 0.3.0

  - Fix configuration regen after configure.ac update
  - Fix test results not shown when testname included a dir name
  - Fix C/C++ standard not set (https://github.com/Mergesium/autotools/issues/15)
  - Fix resolving build, test and check tasks defined in tasks.json (enables CTRL-SHIFT-B default build task)
  - Implement limited ability to parse autoconf projects with manual Makefiles (non-automake)
  - Implement debugging integration tests (eg, shell/python/perl/etc scripts) with one click

  Errata discovered after release will be posted [here](https://github.com/Mergesium/autotools/releases/tag/0.3.0).
